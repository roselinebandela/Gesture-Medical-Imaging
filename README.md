# Gesture Medical Imaging
Gesture-Controlled Medical Imaging  A computer vision project that uses real-time hand tracking and gesture recognition to create a hands-free interface for interacting with medical images. Built with Python, OpenCV, and MediaPipe, the system enables users to navigate, zoom, rotate, and interact with X-ray images using intuitive hand gestures.
